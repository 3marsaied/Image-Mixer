Image Mixer & Corner Detector 🎨🧠

Image Mixer & Corner Detector is a web application that enables users to explore image frequency components by mixing magnitude and phase elements from two images to generate creative results. Additionally, it includes a feature to upload an image and detect its corners. The app is built using Streamlit and provides an interactive, browser-based interface for image experimentation.

🔗 Web App: https://imagemixer.streamlit.app/

🧩 Features

🔀 Image Mixing
Upload two images to split their magnitude and phase components and create new composites by mixing them.

🖼️ Interactive Output
View and compare original and generated images directly in the web interface.

📍 Corner Detection
Upload an image and analyze it to detect and visualize corner points (e.g., using algorithms like Harris or similar).

🌐 Browser-based UI
No installation required — runs fully in the browser via Streamlit.

⚙️ How It Works

Upload two input images.

The app computes their frequency domain representations.

Split into magnitude and phase components.

Mix components to generate new images.

Upload a single image to perform corner detection and see visualized results.

📦 Tech Stack

Streamlit – for the web interface

Python – core application logic

NumPy / OpenCV / SciPy – image processing

HTML/CSS – app layout and design
